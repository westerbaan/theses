# B15 reading (3): the sub-claim (S) is removed

**Verdict: (S) is gone; the theorem is unconditional.** No approximation, no
spectral cutting, no counterexample, no Kadison. Two new steps replace §3–§4
of `B15-elementary.md`, and they *strengthen* the statement:

> **Theorem.** Let `g : 𝒜 → 𝒜` be an ncp-map on a von Neumann algebra with
> `⌈g⌉ = ⌈g(1)⌉` and `g∘g` pure. Then `g` is pure.

Self-contraposition enters only through `⌈g⌉ = ⌈g(1)⌉` (**103III**.1 without
purity, `B15-elementary.md` §1) and again at the very end. The hypothesis
`⌈g⌉ = ⌈g(1)⌉` cannot be dropped: on `ℂ³`, `g(x₁,x₂,x₃) = (x₂+x₃,0,0)` has
`g∘g = 0` pure and `g` impure.

Note first that **(S) is not a theorem**, so it could never have been proved:
`g = c_p` with `p` faithful, not invertible, satisfies every hypothesis and is
not onto its corner (`B15-elementary.md` §5). Route (a) fails for the same
reason — `g(M) ⊇ f(M) = √q M √q` is ultraweakly dense (`⌈q⌉ = 1`) but `g(M)`
is not ultraweakly closed, and there is nothing to upgrade. Routes (b), (c),
(d) are not needed and are commented on at the end.

## Setting (unchanged: `B15-elementary.md` §1–§2)

`e := ⌈g⌉ = ⌈g(1)⌉`, `M := e𝒜e`, and `g` restricts to an ncp endomap of `M`
with `p := g(1)`, `⌈p⌉ = 1`, `⌈g⌉ = 1` (so `g` is faithful on `M`);
`f := g∘g` is pure on `M` with `⌈f⌉ = ⌈f(1)⌉ = 1`. Discard `f = 0` (then
`g = 0`). By **100VII**.1 (`special_pure_maps_1`) `f` is a **filter**, so by
**98II**/**99IX**

    f = c_q ∘ ϑ ,   f(x) = √q ϑ(x) √q ,   q := f(1),  ⌈q⌉ = 1,   (1)

with `ϑ := [f]` an **nmiu**-automorphism of `M`. Write `γ := [g]`, the ncpu
part of **98IX** (`square_f`); since `⌈g⌉ = 1`, `g = c_p ∘ γ`, i.e.
`g(x) = √p γ(x) √p`. The whole theorem is: **`γ` is an ncpu-isomorphism**
(**100III**.3). This is proved in two steps.

## Step A — `γ` sends projections to projections, hence is nmiu

Fix a projection `s ∈ M` and put

    D := γ(s) − γ(s)²  ≥ 0 ,      Ψ := √p γ(s)² √p .

`D ≥ 0` is Kadison–Schwarz for the ncpu-map `γ`, which is the Schur
complement of the 2-positive image of `[[1, s],[s, s]] = [[1,s],[0,0]]*[[1,s],[0,0]] ≥ 0`.
Then

    g(s) = √p γ(s) √p = Ψ + √p D √p .                          (2)

Now the same 2×2 trick applied to `g` itself. With `y := g(s)`,

    N := [[ p, y ],[ y*, Ψ ]] = W*W ≥ 0 ,   W := [[√p, γ(s)√p],[0,0]] ,

so applying the 2-positive map `M₂(g)` and using `g(p) = q`, `g(y) = f(s)`:

    [[ q, f(s) ],[ f(s)*, g(Ψ) ]]  ≥  0 .

Schur complement with a regularised corner gives `f(s)*(q+ε)⁻¹f(s) ≤ g(Ψ)`
for every `ε > 0`. By (1), `f(s) = √q t √q` with `t := ϑ(s)` a projection, so
the left-hand side is `√q t · q(q+ε)⁻¹ · t √q`, which increases to
`√q t ⌈q⌉ t √q = √q t √q = f(s)` as `ε ↓ 0`. Hence

    f(s)  ≤  g(Ψ) .                                            (3)

But applying `g` to (2), `f(s) = g(Ψ) + g(√p D √p)`. With (3) this forces
`g(√p D √p) ≤ 0`; the left side is positive, so it is `0`; `g` is faithful, so
`√p D √p = 0`; `⌈p⌉ = 1`, so **`D = 0`**. Thus `γ(s) = γ(s)²` is a projection
for every projection `s`, and **`γ` is multiplicative** by Gardner
(**99II**, `gardner`; or **99XII**). So `γ` is an nmiu-endomap of `M`.

*Where purity of `f` was used:* only through `ϑ` being **multiplicative** in
(1) — i.e. `f(s)` is "`√q · projection · √q`". That is the exact content of
"`f` is pure", used on the nose, as `B15-elementary.md` §6 predicted.

## Step B — the phase is unitary, so `γ` is onto

`γ` nmiu gives `γ ∘ c_p = c_ρ ∘ γ` with `ρ := γ(p)`, `⌈ρ⌉ = γ(⌈p⌉) = 1`, hence

    f = c_p γ c_p γ = c_p c_ρ γ² = ad_a ∘ γ² ,    a := √ρ √p ,

where `ad_a = a*(·)a`. Its two carriers are both `1`:
`⌈a*a⌉ = ⌈√p ρ √p⌉ = ⌈q⌉ = 1` and `⌈aa*⌉ = ⌈√ρ p √ρ⌉ = ⌈ρ⌉ = 1` (using
`⌈h(b)⌉ = ⌈h(⌈b⌉)⌉`). So `ad_a` is pure (**100II**.3, `isPure_adSelf`) and
faithful, hence a **filter** (**100VII**.1), hence

    ad_a = c_q ∘ β ,   β := [ad_a] an nmiu-automorphism of `M`

— concretely `β = [a](·)[a]*` for the polar phase `[a]`, which is *unitary*
because both carriers of `a` are `1` (**98XI** `ad-pure` + `polar_decomposition`).
Therefore `f = c_q ∘ (β ∘ γ²)` with `β∘γ²` ncpu, so by uniqueness in
**98IX**, `ϑ = [f] = β ∘ γ²`. Both `ϑ` (by (1)) and `β` are **surjective**,
hence `γ²` is surjective, hence so is `γ`:

    γ is an nmiu-automorphism of M .

## Conclusion

`γ = [g]` is an ncpu-isomorphism, so `g` is **pure** by **100III**
(3⟹1); explicitly `g = c_p ∘ γ ∘ π_e` on `𝒜`, a filter after an isomorphism
after a corner. Being pure and contraposed to itself, `g` is ⋄-self-adjoint
(**103I**.1), so `f = g∘g` is ⋄-positive by definition (**103I**.2), and
**105V** (`positive_map_uniqueness`) yields `f = √q(·)√q`, `q = f(1)`. ∎

## Cross-check: the Kraus route closes too, without `*`-closedness

`B15-elementary.md` §7(b) needed the Kraus span `V` to be `*`-closed. It does
not: in type I write `g = Σ ad_{A_k}` minimally, `f = Σ_{k,l} ad_{A_kA_l}`
pure `= ad_W`, so `A_kA_l = c_{kl}W` by Kraus uniqueness. Faithfulness gives
`⋂ ker A_k = 0` and `span ⋃ ran A_k` dense, so (i) `C = (c_{kl})` is
invertible — `Cμ = 0` makes `ran(Σμ_lA_l) ⊆ ⋂ker A_k = 0` — and (ii)
associativity `A_k(A_lA_m) = (A_kA_l)A_m` reads `c_{lm}·A_kW = c_{kl}·WA_m`,
so if `A_kW ≠ 0 ≠ WA_m` for some `k,m` then every column of `C` is
proportional to row `k`, i.e. `rank C = 1`. Otherwise `A_kW = 0` for all `k`
(else `WA_m = 0` for all `m`, so `W = 0`), which forces `W = 0`. Either way
`dim V = 1`: `g = ad_A` is pure. This is the `M₂` hand-check at every rank
and needs no self-adjointness of the `A_k` — but it is type I only, and the
Step A/B proof above supersedes it.

## Verdicts on the other routes

* **(b) `q + ε`**: dead, as suspected. `g_ε∘g_ε` is not pure, and (1) — the
  only place purity is used — is exactly what breaks.
* **(c) spectral corners `q_n`**: not needed. And `g` need *not* commute with
  the spectral projections of `q` in general; what the `M₂` hand-check really
  used is the associativity of Kraus products (see above), whose type-free
  avatar is Step B's `f = ad_a ∘ γ²`.
* **(d) counterexample**: none exists — the theorem is proved in all types.
