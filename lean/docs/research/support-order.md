# The support order `⊑` on maps of a ⋄-effectus

Research note, 2026-09-12. Sources read: proc.tex 1010–1030 (`f^⋄`, `f_⋄`, `diamond-sum`,
`rigid`, `pure-is-rigid`, ⋄-positivity), eff.tex 2030–2160 (`floor-basics`, `lattice-compr`,
`diamond-basics` … `dagger-of-zeta`), dils.tex 1570 (`paschke-correspondence`) and 1710
(`paschke-pure`). Conventions are eff.tex's: `f : X → Y`, `f^⋄ : SPred Y → SPred X`,
`f^⋄(s) = ⌈s ∘ f⌉`, `f_⋄(t) = IM(f ∘ π_t)`, `(f∘g)^⋄ = g^⋄ ∘ f^⋄`. `≤` is the PCM order on
`Par(X,Y)` (`f ≤ g` iff `g = f ⋎ h`); `≡` is ⋄-equivalence. Nothing here is in Lean.

**Definition.** `f ⊑ g` iff `f^⋄(s) ≤ g^⋄(s)` for every sharp `s`.

## 0. Verification of the starting observations (all hold in any ⋄-effectus)

* `f^⋄ ≤ g^⋄` ⟺ `f_⋄ ≤ g_⋄` ⟺ `g^□ ≤ f^□`. Proof: `f_⋄(t) ≤ s^⊥ ⟺ f^⋄(s) ≤ t^⊥`
  (`diamond-adjunction`); put `s := g_⋄(t)^⊥` (sharp by the ⋄-axiom). The `□` form is
  `f^□(s) = f^⋄(s^⊥)^⊥`. So `⊑` is a preorder, its symmetric part is `≡`, and it is
  compatible with composition on both sides (`diamond-functor` + `exc-diam-order-pres`).
* `f ≤ g ⟹ f ⊑ g`: `s∘f ≤ s∘f ⋎ s∘h = s∘(f ⋎ h)` and ceilings are monotone.
* `f ⊑ g ⟹ IM f ≤ IM g` and `⌈1∘f⌉ ≤ ⌈1∘g⌉` (evaluate `f_⋄`, `f^⋄` at `1`).
* **`diamond-sum` is abstract.** Lemma A: in an effectus with images and sharp joins,
  `IM(f ⋎ g) = IM f ∨ IM g`. Proof: `t∘(f⋎g) = 1∘(f⋎g)` iff `t∘f ⋎ t∘g = 1∘f ⋎ 1∘g`
  iff (cancellation in an effect algebra, since `t∘f ≤ 1∘f`, `t∘g ≤ 1∘g`) `t ≥ IM f` and
  `t ≥ IM g`; the least such `t` is `IM f ∨ IM g` (`lattice-compr`). Hence
  `(f⋎g)_⋄ = f_⋄ ∨ g_⋄` pointwise, and `(f⋎g)^⋄ = f^⋄ ∨ g^⋄` by contraposing through the
  adjunction exactly as in `diamond-sum-proof`. Corollary: `⌈p ⋎ q⌉ = ⌈p⌉ ∨ ⌈q⌉`.
* Consequently, whenever `f ⊥ g`: `f ⊑ g ⟺ f ⋎ g ≡ g`, and `f ⋎ g` is a `⊑`-join of `f,g`.

## 1. `⊑` and the PCM structure (abstract)

**Statement 1.** In every ⋄-effectus `(≡ ; ≤ ; ≡) ⊆ ⊑`. If moreover every `f` has a
representative `f' ≡ f` summable with any given `g` ("halving"; true in `vN^op`, `EJA^op`,
`Kℓ(D)` via `f' = ½·f`, cf. `equivalent-examples` 3), then
`⊑ = ≡ ; ≤ ; ≡`, i.e. `⊑` is the preorder generated by the PCM order and ⋄-equivalence.
Proof: `f ⊑ g`, `f' ≡ f`, `f' ⊥ g` ⟹ `f ≡ f' ≤ f' ⋎ g ≡ g` by §0. Conversely `≤ ⊆ ⊑` and
`≡ ⊆ ⊑`. So `⊑` is characterised by the PCM structure *up to* `≡` — but `≡` itself is not
PCM-definable (`z·f ≡ f` for faithful central `z` is invisible to `≤`). Without halving I
expect `⊑ ⊋ ≡;≤;≡` (candidate: an effectus whose scalars are `{0,1}`-like but with a
non-summable pair `f ⊑ g`; not constructed). Confidence: high for the proven parts.

## 2. Rigidity is order-theoretic, and reduces to asserts

`rigid` (proc 1020) says literally: the `≡`-class of `f` inside the fibre `{g : 1∘g = 1∘f}`
is `{f}`. So rigidity *is* the order-theoretic notion; the content is which maps have it.

**Statement 2 (reduction, abstract, &-effectus).** In an &-effectus TFAE:
(a) every pure map is rigid; (b) every quotient is rigid; (c) every `asrt_p` is rigid.
Sketch. (a)⟹(c): asserts are pure. (c)⟹(b): a quotient of `p^⊥` is `ξ = β ∘ ζ_{⌈p⌉} ∘ asrt_p`
with `β` iso (`zeta-asrt-quot`, uniqueness of quotients). If `g ≡ ξ`, `1∘g = 1∘ξ`, then
`g = γ ∘ ξ` with `γ` total, and `π_{⌈p⌉} ∘ β⁻¹γβ ∘ ζ ∘ asrt_p ≡ π ∘ ζ ∘ asrt_p = asrt_p` with
the same `1∘`; rigidity of `asrt_p` and mono/epi-ness give `γ = id`. (b)⟹(a): write
`f = π_{IM f} ∘ α ∘ ξ`, `ξ := ζ_{⌈p⌉} ∘ asrt_p`, `α` iso (`standard-form-map` 1), and
`g = π_{IM f} ∘ β ∘ ξ` (same `IM`, same `1∘`, `β` total). Since `ζ_{IM f} ∘ π_{IM f} = id`,
`π^⋄` is a retraction, hence surjective; cancelling it and `α^⋄` gives `(α⁻¹β ∘ ξ)^⋄ = ξ^⋄`,
so `α⁻¹β ∘ ξ = ξ` by (b), so `β = α`, `g = f`.

**Statement 2′ (an effectus proof of "pure ⟹ rigid", under two extra axioms).**
Assume (S) sharp predicates are jointly monic (`t∘f = t∘g` for all sharp `t` ⟹ `f = g`;
true in `vN^op`, `EJA^op`, `Set`), and (Q) every quotient `ξ` has `ξ_⋄` surjective
(equivalently `ξ^⋄` injective, by the Galois connection). Then all pure maps are rigid.
Proof: with (Q), `ξ^⋄ ∘ γ^⋄ = ξ^⋄` gives `γ^⋄ = id` for the total `γ` of Statement 2, i.e.
`⌈t∘γ⌉ = t`; then `t∘γ ≤ t`, `t^⊥∘γ ≤ t^⊥`, `t∘γ ⋎ t^⊥∘γ = 1 = t ⋎ t^⊥`, so `t∘γ = t` by
cancellation, and `γ = id` by (S). (S) alone already gives: `id`, isos, `π_s`, `ζ_s` rigid.

Where the analysis hides: in `vN^op` (Q) holds for the filter `√p(·)√p` iff `p ≥ ε⌈p⌉`
for some `ε > 0` (bounded inverse on the support). Counterexample otherwise: `ℓ²`,
`√p = diag(1/n)`, `w ∉ ran √p`, `e := proj(w^⊥)`: then `⌈√p e √p⌉ = 1 = ⌈√p 1 √p⌉`, so
`ξ^⋄` is not injective. This is precisely the gap the approximate pseudoinverse in
`canonical-quotient-rigid` closes. So (Q) holds in finite dimensions and in `EJA^op`;
for infinite-dimensional `vN^op` the abstract route needs "asserts are rigid" as an axiom
(Statement 2 shows this is the exact residual). Confidence: high.

## 3. Radon–Nikodym below a pure map; the centre

Define the **centre** of an object as the interval effect algebra `Z(X) := [0, id_X] ⊆ Par(X,X)`.
In `vN^op`, `[0, id]_ncp ≅ [0,1]_{Z(𝒜)}` by `paschke-correspondence` for the pure map `id`
(dilation `(𝒜, id, id)`, commutant `Z(𝒜)`), acting by `a ↦ c a = asrt_c(a)`. So
`Z(X)` is the object-wise centre, and equals the scalars exactly for factors — the scalars
of the effectus are the global `Z(1)`, and `Z(X) ⊇ Scal·id_X` in general.
Equivalently (vN): `c ∈ Z` ⟺ `asrt_c ≤ id` ⟺ `asrt_c ⋎ asrt_{c^⊥} = id` ("c is a
side-effect-free test"); the second ⟺ is again Paschke for `id`.

**Statement 3a (abstract, &-effectus).** Comprehensions and quotients reflect the PCM order:
`[0, π_s] = π_s ∘ Z(X)` and `[0, ξ] = Z(Y) ∘ ξ` for `ξ : X ↠ Y` a quotient.
Proof: `ψ ≤ π_s` ⟹ `IM ψ, IM ψ' ≤ s` ⟹ `ψ = π_s h`, `ψ' = π_s h'`, `π_s(h ⋎ h') = π_s`,
so `h ⋎ h' = id` (mono). Dually `ψ ≤ ξ` ⟹ `1∘ψ ≤ 1∘ξ` ⟹ `ψ = hξ`, `ψ' = h'ξ`, `h ⋎ h' = id`
(epi). Note the sides differ: for `π_s` the centre of the *domain*, for `ξ` of the *codomain*.

**Statement 3b (conjecture, †-effectus).** For every pure `φ : X → Y`,
`[0, φ] = φ ∘ Z(X) = Z(Y) ∘ φ`, and `c ↦ φ ∘ asrt_c` is an order isomorphism from
`{c ∈ Z(X) : c ≤ z_φ}` onto `[0, φ]` for a sharp central `z_φ` (in vN: the central carrier
of `⌈φ⌉`). Evidence: in `vN^op` this is `paschke-pure` + `paschke-correspondence`:
`ρ` surjective ⟹ `ρ(𝒜)^□ = Z(𝒫)`, `𝒫 = cc(⌈φ⌉)𝒜`, `φ_t = φ(c ·)`; and `φ(c a) = z φ(a)`
with `z ∈ Z(ℬ)` because corners, isos and filters each carry `Z(dom)` into `Z(cod)`
(`Z(q𝒜q) = Z(𝒜)q`). What an abstract proof needs beyond 3a: (i) `Z` is lax-functorial along
pure maps, `φ ∘ asrt_c = asrt_{c'} ∘ φ` for some `c' ∈ Z(Y)`; (ii) the two one-sided
reflections of 3a glue along `f = π ∘ α ∘ ξ`. (i) is the real content; for isos it follows
from `asrt-iso` once `Z` is characterised by `asrt_c ≤ id`. Confidence: medium.

**Statement 3c (vN, lattice question).** `[0, φ]_ncp` is a lattice iff `ρ(𝒜)^□` is
commutative (unit interval of a C*-algebra is a lattice iff the algebra is commutative;
Paschke gives the order-iso). Pure ⟹ commutant `= Z(𝒫)` ⟹ lattice, indeed an MV-effect
algebra ≅ `[0,1]` of a commutative vN algebra. The converse fails: an irreducible proper
subfactor `ρ(𝒜) ⊊ 𝒫` has `ρ(𝒜)^□ = ℂ` without `ρ` surjective. Abstract version: "the
`⊑`-class … " is not the right invariant; the right one is the commutant of the dilation (§4).

**Statement 3d (asserts under the three orders, vN).** With `c` ranging over the centre:
`asrt_p ≤ asrt_q ⟺ p = cq, c ∈ [0,1]_Z` (Paschke for the pure `asrt_q`, then apply to `1`);
`asrt_p ≡ asrt_q ⟺ p = cq` with `c ≥ 0` central, *affiliated* (possibly unbounded), and
`⌈c⌉ ≥ cc(⌈q⌉)`; `asrt_p ⊑ asrt_q ⟺ p = cq`, `c ≥ 0` central affiliated. In a factor:
`⊑` on asserts is "proportional with `c ≥ 0`", `≡` is the ray relation `c > 0`.
Proof (factor): `s = |v⟩⟨v|` gives `√p v ∈ ℂ√q v` for all `v`, hence `√p = c√q` by the
linear-algebra lemma "`Av ∈ ℂBv ∀v ⟹ A = cB`". **The bounded form in the brief is false**
in general: `L^∞[0,1]`, `p = √x`, `q = x`: supports agree so `asrt_p ⊑ asrt_q` (commutative
case: `⊑` = support inclusion), but `p/q = x^{-1/2} ∉ L^∞`. General-vN direction ⟹ is a
conjecture (reduce over the centre; direct-integral heuristic). Side remark: `⊑` on asserts
collapses to the ceiling order `⌈p⌉ ≤ ⌈q⌉` iff the algebra is commutative (in `M_2`,
`⌈p⌉ ≤ ⌈q⌉` is far weaker than `p ∝ q`).

## 4. An abstract Paschke correspondence

Let `C` be an &-effectus (or ⋄-effectus) with a distinguished wide subcategory `𝒮` of
"sharp/nmiu" maps (`sharp-map` is the natural choice: `exa-sharp-vn`). A **dilation** of
`φ : X → Y` is `(P, ρ ∈ 𝒮, h)` with `φ = h∘ρ` such that for every `φ = h'∘ρ'`, `ρ' ∈ 𝒮`,
there is a unique `σ` with `σ∘ρ' = ρ`, `h∘σ = h'` (the thesis's universal property, in
effectus direction). Define the **commutant of `ρ : X → P`** as
`ρ^□ := {t ∈ Pred P : asrt_t ∘ ρ ≤ ρ}`; in vN this is `ρ(𝒜)^□ ∩ [0,1]` (Paschke for `ρ`,
whose dilation is `(P, ρ, id)`, then evaluate at `1`). Note `ρ^□ ⊇ Z(P)` always.

Axioms needed for `[0, φ] ≅ ρ^□`, `t ↦ h ∘ asrt_t ∘ ρ`:
(P1) dilations exist for all maps; (P2) *commutant lemma for `𝒮`*: `t ↦ asrt_t ∘ ρ` is an
order iso `ρ^□ → [0, ρ]` for `ρ ∈ 𝒮`; (P3) *minimality*: `h` restricts to an order iso
`[0, ρ] → [0, h∘ρ]`. Then `[0,φ] ≅ [0,ρ] ≅ ρ^□`. In vN, (P2) is Paschke prop 5.4 for
homomorphisms and (P3) is the "order embedding / surjectivity" half of
`paschke-correspondence` (the `W = W*W` construction) — both proved with the inner product,
so (P3) is genuinely analytic and I do not see it following from (P1). Independence of (P3)
from (P1)+(P2): open. Consequences: `φ` pure ⟺ `ρ` epi-in-`𝒮` (`paschke-pure`) ⟹
`ρ^□ = Z(P)`, which recovers 3b; "`[0,φ]` lattice ⟺ `ρ^□` commutative" needs the extra
Sherman-type fact and has no effectus analogue yet. Confidence: axioms plausible; not
checked against `EJA^op`, where Paschke dilations are not known to exist.

## 5. Small extra facts

* In a †-effectus the dagger is `⊑`-monotone on `Pure C`: `f ⊑ g ⟹ f† ⊑ g†`
  (`f†_⋄ = f^⋄ ≤ g^⋄ = g†_⋄`). Hence `≡`-classes are †-stable.
* `f ⊑ g` and `f ⋄-adjoint f'`, `g ⋄-adjoint g'` ⟹ `f' ⊑ g'` (same computation).
* `rigid-ncp-extreme` is abstract given halving: the proof uses only `diamond-sum` and
  `z·f ≡ f` for faithful scalars.

## Best conjecture (also the report)

Statement 2/2′: in an &-effectus, "all pure maps rigid" ⟺ "all asserts rigid" ⟺ "all
quotients rigid" (proved abstractly), and holds outright when sharp predicates are jointly
monic and every quotient `ξ` has `ξ_⋄` surjective — an effectus proof of `pure-is-rigid`
for `EJA^op` and finite-dimensional `vN^op`; the infinite-dimensional gap is exactly the
non-injectivity of `ξ^⋄` for filters with `0` in the spectrum of `p` on its support.
