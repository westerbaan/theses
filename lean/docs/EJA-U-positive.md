# `U_a` preserves the cone: an elementary proof for the tree

**Verdict: proof found.**  It does not need Macdonald, the fundamental formula,
Shirshov–Cohn, or any topology of the cone.  It does not go through the 2×2
Cauchy–Schwarz of the `beff-vnexamples.csv` 206III row at all — that inequality
is a *corollary* below, not the gap.  Estimated Lean cost 900–1500 lines, of
which the new mathematical content is about 60.

Notation: `q` an idempotent, `P₁ = ejaPone q`, `P½ = ejaPhalf q`,
`P₀ = ejaPone (1-q)`, `B = ejaB`, `U_a = 2 L_a² - L_{a²}` (so `U_q = P₁`).

## 1. The pivot: don't test against idempotents, compute `U_a g` for `g` primitive

Call an idempotent `g ≠ 0` *primitive* when `V₁(g) = ℝ g`.  The whole theorem
is the following identity, proved by four lines of Peirce arithmetic.

**Lemma (core).** Let `q, g` be idempotents with `g` primitive, `t ≥ 0`.  Put
`c = P₁ g`, `z = P½ g`, `d = P₀ g`, `σ = B q g / B g g`, and
`f = c + t•z + t²•d` (`= U_{q + t(1-q)} g`, see §3).  Then

    f * f = μ • f,   μ = σ + t²(1-σ) ≥ 0,

hence `f = μ • (μ⁻¹ • f)` with `μ⁻¹ • f` idempotent, so `0 ≤ f` (and `f = 0`
when `μ = 0`, since `B f f = ejaTrL (f*f) = 0`).

*Proof.* `U_g q` lies in `V₁(g) = ℝ g`, so `U_g q = σ • g` with
`σ = B q (U_g g) / B g g = B q g / B g g` (`U_g g = g`; `ejaB_pone_self_adj`).
Expand `U_g q = 2 g*(g*q) - g*q` in the Peirce components of `q`, using
`q*g = c + ½z`, `c*d = 0`, `P½(z*z) = 0`, `c*z, d*z ∈ V½`:

    U_g q = (c - P₁(z*z)) + 2•(c*z) + P₀(z*z).

Matching against `σ•(c + z + d)` in `V₁ ⊕ V½ ⊕ V₀` gives three relations, and
`g*g = g` gives `c = c*c + P₁(z*z)`, `d = d*d + P₀(z*z)`:

    c*c = σ•c,   d*d = (1-σ)•d,   z*z = (1-σ)•c + σ•d,
    2•(c*z) = σ•z,   2•(d*z) = (1-σ)•z.

Then, with `c*d = 0`,

    f*f = c*c + t²•(z*z) + t⁴•(d*d) + t•(2 c*z) + t³•(2 d*z)
        = [σ+t²(1-σ)]•c + [t²σ+t⁴(1-σ)]•d + t[σ+t²(1-σ)]•z = μ•f.

`0 ≤ σ ≤ 1` because `B q g ≥ 0` and `B (1-q) g ≥ 0` (both pairs in the cone)
and `B q g + B (1-q) g = B 1 g = ejaTrL g = B g g > 0`.  ∎

Sanity checks: in `Sym_n` with `g = v vᵀ` this is `(DvvᵀD) = |Dv|²·rank-one`,
`D = diag(1,t)`, `σ = |v₁|²`; in a spin factor `q = ½(1,e)`, `g = ½(1,s)`,
`σ = (1+s·e)/2`, `μ = σ + t²(1-σ)`.  Both agree.

  `eja_commute_of_peirce_one`, and `q*(d*c) = d*(q*c) = d*c` by
  `eja_commute_of_peirce_zero`; so `c*d = 0`.
* `c*z ∈ V½` for `c ∈ V₁`, `z ∈ V½`: `q*(c*z) = c*(q*z) = ½•(c*z)`; same for
  `d*z` with the `peirce_zero` version.
* `P½(z*z) = 0` for `z ∈ V½`: instantiate `eja_lin q z z q`.  With
  `q*z = ½•z`, `q*q = q`, four of the six terms cancel in pairs and what is
  left is exactly `q*(q*(z*z)) = q*(z*z)`, i.e. `ejaPhalf q (z*z) = 0`.
* `V₁`, `V₀` are subalgebras: already in the tree (`EJACorner`).

So the mathematical core of §1 plus §2 is ≈ 60 Lean lines of real content.

## 3. From the core lemma to the theorem

**(a) The two-valued `U`.**  `L_q = P₁ + ½P½` is the tree's
`ejaLm_eq_peirce`; with `P½(1-q) = P½ q` and `P₁(1-q) = P₀` one gets
`L_{λq+μ(1-q)} = λP₁ + ½(λ+μ)P½ + μP₀`, `(λq+μ(1-q))² = λ²q + μ²(1-q)`, and
the three projections are orthogonal idempotents summing to `id`, whence

    U_{λ•q + μ•(1-q)} = λ²•P₁ + λμ•P½ + μ²•P₀.

**(b) Every idempotent is a sum of orthogonal primitives.**  Induct on
`dim V₁(e)`.  If `V₁(e) ≠ ℝe`, the corner `EJACorner e` is an EJA of dimension
≥ 2, so the spectral theorem there yields an idempotent `0 ≠ p ≠ e` with
`p ≤ e`; then `e = p + (e-p)`, orthogonal, and `V₁(p) ⊊ V₁(e)` (`e ∉ V₁(p)`).

**(c) The cone is generated by primitive idempotents.**  `eja_spectral` plus
`eja_ortho_isSumSq_iff` write `0 ≤ x` as `x = Σ λᵢ•eᵢ`, `λᵢ ≥ 0`, `eᵢ`
orthogonal idempotents; refine each `eᵢ` by (b).  With §1 and (a),
`U_{λq+μ(1-q)}` maps the cone into the cone for all `λ, μ ≥ 0` (rescale
`f` by `λ²`; `λ = 0` is `μ²P₀`, already in the tree).

**(d) General `a ≥ 0`, by induction on the spectral support.**  Write
`a = λ•c + a'` with `c` a spectral idempotent of `a` and `a' ∈ V₀(c)`, and put
`d₁ = λ•c + (1-c)`, `d₂ = c + a'`.  Then

    U_a = U_{d₁} ∘ U_{d₂},

checked on the three Peirce spaces of `c`: on `V₁` both sides are `λ²`, on
`V₀` both are `U_{a'}` restricted there, and on `V½`, writing `A = L_{a'}|V½`,
`U_a = 2λA + 2A² - L_{a'²}` and `U_{d₁}U_{d₂} = λ(2A + 2A² - L_{a'²})`; these
agree because `U_{a'}` kills `V½(c)` when `c*a' = 0`, i.e. `2A² = L_{a'²}` on
`V½` — the one further Peirce identity to prove (a linearisation exercise, cf.
`eja_lin a' a' c y`; ≈ 40 lines).  `d₁` is two-valued, so `U_{d₁}` preserves
the cone by (c); `d₂` has one fewer spectral value ≠ 1, so `U_{d₂}` preserves
it by induction; the base case `a = 1` is `U_1 = id`.

## 4. Corollaries

* `0 ≤ a → 0 ≤ x → 0 ≤ U_a x` (in fact for *every* `a`, since (d) never uses
  `λᵢ ≥ 0` beyond `U_{λc+(1-c)}` — and (c) covers `λ < 0` by `λ²`).
* The 206III row's inequality falls out: for idempotents `g, h`,
  `B (P½ g) (P½ h)² ≤ 4 · B (P₁ g) (P₁ h) · B (P₀ g) (P₀ h)`.  Indeed
  `B (U_{q+t(1-q)} g) h = α + tβ + t²γ ≥ 0` for all `t > 0` with
  `α = B (P₁g) (P₁h)`, `β = B (P½g) (P½h)`, `γ = B (P₀g) (P₀h)`; the
  discriminant is the claim.  So the row's "that single Cauchy–Schwarz is the
  whole gap … its classical proofs go through data this tree has not got" is
  the wrong reading of the obstruction: the inequality is not the natural
  intermediate statement — `U_a g` for `g` primitive is.
* The quotient/filter of 206III's `EJAᵒᵖ` clause is then unblocked; the row's
  ≈ 250 lines for the frame multiplicativity is replaced by §3(d), and the
  "unknown" two-valued case by §1.

## 5. Why the three routes in the brief do not work

* **(i) Self-duality + discriminant.**  The free data gives exactly the wrong
  endpoint and no more.  `σ_q = P₁ - P½ + P₀` is a Jordan automorphism (the
  `ℤ/2`-grading `V₁⊕V₀ / V½` of the Peirce rules), so `σ_q g` is again an
  idempotent and `B (σ_q g) h ≥ 0` gives `|β| ≤ α + γ` for free.  That is
  *sharp* (rank-one in `Sym₂`), and it is exactly the AM–GM weakening of the
  wanted `|β| ≤ 2√(αγ)`.  Consequently the otherwise attractive bootstrap —
  `T_s T_t = T_{st}` (immediate, as `P₁,P½,P₀` are orthogonal idempotents), so
  positivity on any interval around `t = 1` would give all `t > 0` — cannot be
  started: `|β| ≤ c(α+γ)` with `c < 1` is false, and `c = 1` yields
  positivity only at `t = 1`.  Any proof along these lines must therefore
  break the symmetry between `x` and `y`, which is what §1 does by taking one
  of them primitive.
* **(ii) `U_a = U_{√a}²`.**  In the two-valued case this is free
  (`T_t = T_{√t}²`), no fundamental formula needed — and useless:
  `B (T_t x) y = B (T_{√t}x) (T_{√t}y)` needs *both* arguments in the cone,
  which is the statement itself.  Squares do not help either: `B u v ≥ 0`
  requires `u, v ≥ 0`, not `u, v` squares of the same map's images.
* **(iii) The compression argument.**  `eja_pone_nonneg` works because `U_q`
  *fixes* the corner's idempotents: `B (U_q x) g = B x (U_q g) = B x g ≥ 0`.
  For a two-valued `a` the same computation returns `B x (U_a g)`, i.e. the
  statement for idempotents again — circular, whichever corner one works in.
  §1 escapes precisely by computing `U_a g` rather than pairing with it.
